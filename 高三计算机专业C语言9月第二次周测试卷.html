四、代码改错题（每题5分，共15分）
1.（5分）
错误一：x = 10 语句末尾缺少分号。（2.5分）应改为：x = 10;
错误二：if (x = 5) 中 "=" 是赋值运算符，条件恒为真。（2.5分）应改为：if (x == 5)
2.（5分）
错误一：c = a / b; 中 a、b 均为整型，执行整数除法结果为 2。（2.5分）应改为：c = (float)a / b; 或 c = 1.0 * a / b;
错误二：(a + b)++; 自增运算符的操作数必须是变量（左值），不能是表达式。（2.5分）应删除该语句，或改为 a++; b++;
3.（5分）
错误一：printf("%d\n", c); 中 c 为 float 型，格式符应使用 %f。（2.5分）应改为：printf("%f\n", c);
错误二：if (a = 8) 中 "=" 是赋值运算符，条件恒为真。（2.5分）应改为：if (a == 8)
