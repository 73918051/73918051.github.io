四、代码改错题（4×10=40分，每个错误5分）
1. ① 第4行缺少分号 → 改为 int a, b, sum;   ② 第5行 scanf("%d%d", a, b); 缺少 & → 改为 scanf("%d%d", &a, &b);
2. ① char c = "A"; 字符串不能赋给char → 改为 char c = 'A';   ② printf("%c\n", c); 应输出ASCII码 → 改为 printf("%d\n", c);
3. ① define PI 3.14 缺少 # → 改为 #define PI 3.14   ② float result = PI * 5 缺少分号 → 改为 float result = PI * 5;   ③ printf("result = %d\n", result); 格式与类型不匹配 → 改为 printf("result = %f\n", result);（任选2个错误）
4. ① 变量 z 未定义 → 在函数体开头添加 int z;   ② if 语句块未用 { } 括起来（或 else 后缺少语句块） → 改为 if (x > y) { z = x; } else { z = y; }

1. ① "%d%d"   ② a + b
2. ① #define   ② PI * r * r 或 PI * r * r
3. ① n % 2 == 0   ② "奇数"
4. ① max(a, b)   ② z = x
5. ① i <= 10   ② sum + i
