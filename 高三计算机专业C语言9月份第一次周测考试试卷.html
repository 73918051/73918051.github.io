四、代码改错题（每题10分，共30分）
1.（10分）
错误一：a == 5; 是关系运算，不能完成赋值。（5分）应改为：a = 5;
错误二：printf("%d\n", a) 语句末尾缺少分号。（5分）应改为：printf("%d\n", a);
2.（10分）
错误：++(a+b); 自增运算符的操作数必须是变量（左值），不能是表达式。（10分）
改正：删除该语句，或改为 a++; b++;（写出其中之一即可）
3.（10分）
错误一：c = a/b; 中 a、b 均为整型，执行整数除法结果为2，赋给c得2.000000。（5分）应改为：c = (float)a/b; 或 c = 1.0*a/b;
错误二：if (a = 6) 中 "=" 是赋值运算符，条件恒为真。（5分）应改为：if (a == 6)
