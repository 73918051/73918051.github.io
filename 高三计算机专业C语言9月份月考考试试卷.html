int main()

1. 4 5 8
解析：x++ 返回 3，x 变为 4；++y 返回 5；z=3+5=8。

解析：8/3=2；8%3=2；(float)8/3=2.666…，保留一位小数输出 2.7。
3. 5 10 1
解析：a>3 为真，执行 b=10，c=1。
4. 3　　4　　15

四、代码改错题（每题4分，共12分）
1. 错误：sum == a + b; 是关系运算，不能赋值。（2分）
改正：sum = a + b;（2分）
2. 错误：c = a / b; 中 a、b 均为整型，整数除法结果为 3。（2分）
改正：c = (float)a / b; 或 c = 1.0 * a / b;（2分）
3. 错误：if (x = 10) 是赋值运算，条件恒为真。（2分）
改正：if (x == 10)（2分）
