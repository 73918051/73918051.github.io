平台模型与关键考点
平台：64 位，小端序；char=1、int=4、long=4（Windows）/ 8（Linux 64 位）、指针=8。
FILE 类型：系统库内部结构体；fp 是 8 字节句柄地址，示意值 0x5A2C。
★ fseek 三参数三基准点：fseek(fp, 0, SEEK_END)
　第 1 个 = 文件指针；第 2 个 = 偏移量；第 3 个 = 基准点。
　SEEK_SET（值 0）= 文件开头
　SEEK_CUR（值 1）= 当前位置
　SEEK_END（值 2）= 文件末尾
★ fseek 只挪位置、不读数据：不管文件多大都是 O(1)。
★ ftell 返回当前偏移量：位置在末尾时，偏移量 = 文件长度。
★ long 配 %ld：不能写成 %d；64 位 Linux 上 long 是 8 字节。
★ "r" 打开方式：只读，文件必须已存在；默认文本模式。
★ 路径转义：源码 "d:\\study.txt" 运行时是 d:\study.txt。
★ 打开文件必判空：第 6 行；文件不存在 / 无权限都会返回 NULL。
原程序小瑕疵：第 6 行错误分支里也写了 return 0，应改为 return 1 表示失败。
★ fclose 必须配对：一个 fopen 一个 fclose。
★ 文件关闭后 length 仍有效：它是普通变量的副本。
★ O(1) vs O(n)：fseek+ftell 瞬间算完；while+fgetc count++ 要读整个文件。
★ 文本模式下 ftell 可能不准：\r\n 转换问题；精确字节数用 "rb"。
★ printf 的 \n 作用：让光标换行，提示符不紧贴数字。
复杂度：时间 O(1)，空间 O(1)。
