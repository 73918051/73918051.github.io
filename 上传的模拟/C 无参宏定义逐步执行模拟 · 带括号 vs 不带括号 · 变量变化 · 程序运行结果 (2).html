★★★ 宏的本质：预处理阶段的纯文本替换，不是函数，不做类型检查，不占运行时内存。编译后程序里只剩替换后的表达式。
★★★ 带括号 vs 不带括号：
· A = (x*x+2*x) → 2*A = 2*(x*x+2*x) = 30 ✔
· B = x*x+2*x → 2*B = 2*x*x+2*x = 24 ✘（缺外层括号）
★★ 嵌套宏展开：
· P = (A*y+c) → ((x*x+2*x)*y+c)，代入 x=3,y=2,c=11 → 41
· 3*R → 3*B*y+c → 3*x*x+2*x*y+c，按优先级拆为 (3*x*x)+(2*x*y)+c → 50
★ 字符串字面量不被替换：printf("(A*y+c)=%d \n", P) 里的 A、y、c 位于字符串内部，原样输出。
★ #undef 撤销宏：撤销 A / B / M / P；程序中未 #undef R，R 仍有效。
★ printf vs scanf：printf 只读取值（传值）；scanf 要修改变量（传地址 &x）。
★ 变量赋值是覆盖式的：c 先第 9 行是 7，第 17 行被覆盖成 11；宏 P 里引用的 c 取执行到该行时的最新值。
★ 局部变量未初始化：x, y, s1, s2, c 是栈上垃圾值（显示为 ?），a=3, b=4 有初始化式。
