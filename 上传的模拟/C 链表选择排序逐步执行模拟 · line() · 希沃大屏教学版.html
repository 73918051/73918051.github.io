🖥 平台模型 & 教学要点
◆ 64 位模型 · 小端序：char=1，int=4，指针 =8；struct node 对齐 8，大小 24 字节
◆ 原链表 3 结点：0x1000(Tom/1/85) 0x1020(Jerry/2/92) 0x1040(Spike/1/78)
◆ 调用 line(h)：按 data 升序排序，返回新表头 0x1040
◆ 选择排序三段式：每一轮都执行「① 遍历找最小 → ② 尾插到有序链 → ③ 从原链摘除」，顺序不能乱。
◆ for 三表达式：for(p=h, pmin=h; p->next!=NULL; p=p->next)；条件是 p->next != NULL（不是 p != NULL），保证循环体内 p->next 可安全解引用，且 p 正好落在前驱位置。
◆ p->next->data 比较：拿「下一个结点」和当前最小值比；一旦发现更小的，p 正好是它的前驱，可以顺手 pmin_before = p;。
◆ 先记前驱，后改最小：pmin_before = p; 必须在 pmin = p->next; 之前，顺序不能反。
◆ 首插特判：if(top == NULL) { top = pmin; p_tail = pmin; }——第一个进入有序链的结点同时是头也是尾。
◆ 尾插先接后移：p_tail->next = pmin; 先于 p_tail = pmin;；顺序反了就断链。
◆ 摘除两分支：pmin == h 时移头指针（无前驱可用）；否则前驱跳过被选结点。
◆ ⚠ pmin_before 未初始化 + 每轮不重置：第 4 行声明时未赋初值，且每轮 for 不重置，会残留上一轮的值；本例恰好因为都走 pmin == h 分支才侥幸安全。建议声明时初始化 = NULL。
◆ if(top != NULL) 收尾置 NULL：给有序链表显式画终止符；这层 if 保护「原链表一开始就是空」的情况（那时 p_tail 从未被赋值）。
◆ ⚠ 不接收返回值 = 入口丢失：调用方写 line(h); 而不接收返回值，h 仍是原指针，但旧的 next 关系已被破坏 → 整条链表失联，等价于泄漏。正确写法 h = line(h);
◆ 原地重排 + O(n²)：全程只改 next 指针，从不 malloc/free；每轮从头扫到尾，n 个结点约 n²/2 次比较。
