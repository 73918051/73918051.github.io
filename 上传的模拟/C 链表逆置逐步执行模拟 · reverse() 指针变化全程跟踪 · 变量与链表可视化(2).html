平台模型 · 关键结论
平台：64 位，小端序；int=4B，指针=8B
  • struct Node → 16 字节；val(偏移 0, 4B) + 填充(4B) + next(偏移 8, 8B)
  • 初始化三步顺序 → p = h; → t = p->next; → p->next = NULL;；顺序不能乱
  • 循环体四步顺序 → p = t; → t = t->next; → p->next = h; → h = p;；顺序不能乱
  • 先存后路 → ②在③之前、⑤在⑥之前：改指针前先保存后继
  • 头插法两动作 → p->next = h;（接链）+ h = p;（移头）
  • 就地逆置 → 不申请新结点；结点地址不变；链表长度不变
  • 原头变尾 · 原尾变头 → 原地逆置的直接后果
  • 函数栈帧 → 返回时自动销毁；堆上的结点仍然存活
  • 返回值 → return h; 返回 0x1040（新头），不是 0x1000
  • while 判断 3 次 → 真 → 真 → 假；循环体执行 2 轮
初始：h = 0x1000 → 0x1020 → 0x1040 → NULL（值 1 2 3）
逆置：h = 0x1040 → 0x1020 → 0x1000 → NULL（值 3 2 1）
⚠ 原程序缺陷：① 空链表未判空（h == NULL 会导致空指针解引用）② 头文件不完整
