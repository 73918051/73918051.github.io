平台模型 · 关键结论
平台：64 位，小端序；int=4B，char=1B，指针=8B
  • struct LNode → 每个结点 32 字节，堆上 malloc 分配
  • name[8] · class · score[4] · next
  • 函数调用 → 实参复制 + 栈帧新建 + 控制权跳转 + 返回后继续
  • 函数栈帧 → 返回时自动销毁，局部变量消失；堆上结点仍然存活
  • 值传递 → main 的 n 与 create 的 n 是不同变量
  • h = NULL → 判断第一个结点的前提
  • h = p; t = p; → 第一个结点既是头也是尾
  • t->next = p; t = p; → 接到链尾并更新尾指针
  • t->next = NULL → 链表封口，漏掉会越界崩溃
  • return h → 返回头指针；返回 p/t 会丢头、内存泄漏
  • while(q) + q = q->next → 链表遍历套路
  • strcpy → 字符串拷贝；数组名不可赋值
  • scanf → 数组名不加 &，普通变量必须加 &
  • printf 不换行 → 追加到同一行；putchar('\n') 收尾换行
最终链表：q = 0x1000 → 0x1020 → 0x1040 → NULL
⚠ 原程序缺陷：① 缺 include <stdlib.h>/<string.h> ② 不查 NULL ③ scanf("%s") 越界风险 ④ 不 free
