平台模型与关键考点
平台：64 位，小端序；char=1、int=4、指针=8。
struct LNode：data 偏移 0（4B）+ 填充 4B + next 偏移 8（8B）= 16 字节。
★ 成环关键句：第 19 行 t->next = h; 尾结点指回头结点；漏掉则 next 是垃圾值，遍历访问非法内存直接崩溃。
★ 尾插法：首结点 h = p; t = p;（同时定头定尾）；否则 t->next = p; t = p;（先接后移）。
★ 先输出头再循环：while(q != h) 初值 q 就是 h，直接循环一次都不执行，所以必须先 printf 头结点、再 q = q->next;。
★ 循环条件：用 q != h，不能用 q != NULL——尾结点 next 指回头结点，永远不为 NULL。
原程序缺陷：n == 0 时 t 未初始化，第 19 行是未定义行为；空链表 q->data 解引用风险；malloc / scanf 返回值未检查；程序结束未 free。
复杂度：建表 O(n)，遍历 O(n)，整体 O(n)；空间 O(n)。
