平台模型与关键考点
平台：64 位，小端序；char=1、int=4、指针=8。
struct node：count 偏移 0（4B）+ data[20] 偏移 4（20B）+ next 偏移 24（8B）= 32 字节。
★ strcmp 字符串比较：字符数组名是地址，str == "stop" 比较的是地址永远为假，必须用 strcmp(str,"stop") == 0。
★ 短路求值保护空指针：while(p != NULL && strcmp(p->data,str) != 0)——左假时右边不求值，防止 p->data 对空指针解引用。
★ 查找循环退出两种状态：p != NULL（找到）→ p->count++；p == NULL（没找到）→ 新建结点。
★ strcpy 复制字符串：数组不能整体赋值，s->data = str 只复制地址，必须用 strcpy。
★ s->next = NULL 不能省：否则尾结点 next 是垃圾值，遍历时访问非法内存崩溃。
★ 尾插两步：首结点 h=s; t=s;（同时定头定尾）；否则 t->next=s; t=s;（先接后移）。
★ p->count++ 优先级：-> 高于 ++，等价于 (p->count)++。
★ disp 形参值传递：函数内 p = p->next 只让副本移动，不影响 main 的 p。
原程序缺陷：scanf("%s", str) 溢出风险；malloc / scanf 返回值未检查；程序结束未 free。
复杂度：查找 O(n)，建表整体 O(n²)；遍历 O(n)。
