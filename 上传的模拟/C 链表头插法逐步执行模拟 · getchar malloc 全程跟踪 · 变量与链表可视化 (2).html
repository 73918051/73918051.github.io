平台模型 · 关键结论
平台：64 位，小端序；char=1B，指针=8B
  • struct Node → 16 字节；ch(偏移 0, 1B) + 填充(7B) + next(偏移 8, 8B)
  • 头插法核心两步 → p->next = h; 先，h = p; 后；顺序不能颠倒
  • 顺序反转 → 输入 abc → 链表 c → b → a
  • getchar 循环 → 读到 '\n' 结束；换行符不入链
  • 全局变量 h → 程序启动时为 NULL；不属于任何函数栈帧
  • 函数调用 → main → create → main；实参复制 + 栈帧新建 + 控制权跳转
  • 函数栈帧 → 返回时自动销毁；堆上的结点仍然存活
  • malloc → 堆上分配，返回 void *，不清零，失败返回 NULL
  • 遍历套路 → while(q) + q = q->next
  • printf("%c ") → 每字符后跟一个空格；最终输出 c b a
最终链表：h = 0x1040(c) → 0x1020(b) → 0x1000(a) → NULL
⚠ 原程序缺陷：① 使用非标准 #include <malloc.h> ② 不检查 NULL ③ 没有 free ④ getchar 返回值应接 int
