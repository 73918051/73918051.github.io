平台模型与关键考点
平台：64 位，小端序；char=1、int=4、指针=8。
★ argc 含程序名本身：argc = argument count = 参数总个数；
　用户只输入 2 个参数（hello、world），argc 却是 3。
★ argv 结构：char *argv[] 是字符串指针数组；
　argv[0] = 程序自己的名字（"prog.exe"）；
　argv[1..argc-1] = 用户参数；
　argv[argc] = NULL 是标准规定的结束哨兵。
★ char *argv[] ≡ char **argv：函数参数里数组名退化为指针。
★ 两个循环起跑线不同：
　第一个 for(i=0; ...) → 打印全部（含程序名），共 3 次；
　第二个 for(i=1; ...) → 统计用户参数（跳过程序名），共 2 次。
　若第二个写成 i=0，len 会多出 8，变成 18。
★ for 循环四步顺序：初始化 → 判断 → 循环体 → 自增 → 回到判断。
★ 循环退出后计数器多 1：两个循环退出时 i = 3。
★ strlen 不含 \0：strlen("hello") = 5，内存占用是 6 字节。
★ 绝不能用 sizeof 代替 strlen：argv[i] 是 char * 指针，
　sizeof(argv[i]) 只返回指针大小（4 或 8），不是字符串长度。
★ len += x 复合赋值：等价于 len = len + x。
★ 累加器必须先清零：len = 0 是硬性要求。
★ 第 9 行 printf 末尾缺 \n：len=10 输出后光标不换行（小瑕疵）。
★ 第 6 行格式串里有空格：%s 与 \n 之间。
★ 循环边界必须是 i < argc：不能写 i <= argc，
　否则会打印 argv[argc] = NULL，用 %s 打印 NULL 是未定义行为（多数系统崩溃）。
★ %d / %s 与类型必须配对：%d ← int，%s ← char*。
i 未初始化：int i, len = 0; 本例安全（两个 for 先赋初值），
　严格写法应是 int i = 0, len = 0;。
复杂度：时间 O(argc × 平均参数长度)，空间 O(1)。
