🖥 平台模型 & 教学要点
◆ 64 位模型 · 小端序：int=4，指针 =8，struct node 对齐 8，大小 16 字节
◆ 堆上 4 个结点：0x1000(85) 0x1020(92) 0x1040(78) 0x1060(90)
◆ 短路求值：while(p != NULL && p->data != score)，左边 p != NULL 先求；为假时右边被跳过，这正是防止空指针解引用的关键。
◆ 循环退出两种原因：① p == NULL（走完没找到）；② p->data == score（命中）。本例是②。
◆ 计数器 i 从 0 开始：命中时 i = 2，输出 NO.2；想显示「第几个」应输出 i + 1。
◆ 代码先 p = p->next，后 i++；所以 p 落在第 k 个结点时 i = k。
◆ ⚠ 空指针隐患：未找到时 p == NULL，if(p->data != score) 会解引用空指针 → 崩溃。严谨写法应先判 if(p == NULL)。
◆ 查找是只读操作：不修改任何 data / next，查找前后链表完全一致。
◆ 原程序缺陷：① 返回类型 void * 却没有 return 语句，返回值未定义；② 未找到时空指针解引用；③ 头文件不完整（缺 #include 与 typedef）；④ 输出格式串末尾没有 \n。
