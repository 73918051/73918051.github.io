🖥 平台模型 & 教学要点
◆ 64 位模型 · 小端序：char=1，int=4，指针 =8；struct node 对齐 8，大小 24 字节
◆ 原链表 3 结点：0x1000(Tom/1/85) 0x1020(Jerry/2/92) 0x1040(Spike/1/78)
◆ 调用 delnode(h, 3)：删除第 3 个结点 0x1040 (Spike)
◆ 短路求值：while(t != NULL && j < i-1)，左边 t != NULL 先求；为假时右边被跳过，防止空指针解引用。
◆ 循环退出两种原因：① t == NULL（位置超出范围）；② j == i-1（定位到前驱）。本例是②。
◆ 计数器 j 从 1 开始：表示 t 当前在第几个结点；退出时 j = i-1 = 2。
◆ 中间删除两步：先 p = t->next;（抓）后 t->next = p->next;（断）；顺序不能反，否则丢失被删结点地址，无法 free。
◆ 断链后：被删结点从 h 出发不可达，但内存仍在堆上；必须 free 才回收。
◆ free(p) 后：p 变成悬空指针，绝不能再访问；稳妥写法 free(p); p = NULL;
◆ 栈上局部变量自动销毁 vs 堆上内存必须手动 free：结点是 malloc 出来的，必须手动 free。
◆ ⚠ BUG 1：i == 1 分支只写了 h = h->next;，从未给 p 赋值；而 free(p); 是无条件执行的 → 删头结点时释放随机地址，未定义行为。正确：p = h; h = h->next; 后再 free(p)。
◆ ⚠ BUG 2：h = h->next; 只改形参副本，调用者 main 的头指针不会变；要真正改必须传 NODE **h。
◆ ⚠ BUG 3：i = 长度+1 时（例：链表长 3，i=4）：循环让 t 停在尾结点，p = t->next = NULL，t->next = p->next 对空指针解引用 → 崩溃。本函数对此无防护。
◆ 头文件不完整：缺 #include <stdio.h>、#include <stdlib.h>、typedef struct node … NODE;
◆ 本程序没有 printf / scanf；控制台仅显示模拟器旁注（[free] ... / [delnode] ...）。
