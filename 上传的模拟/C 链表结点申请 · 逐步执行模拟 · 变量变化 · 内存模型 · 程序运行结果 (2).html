平台模型 · 关键结论
平台：64 位，小端序；int=4B，指针=8B，char=1B
  • struct LNode → 对齐 8，sizeof = 16（不是 12）
  • data → 偏移 0，4 字节
  • 填充 → 偏移 4，4 字节，为满足 next 的 8 字节对齐
  • next → 偏移 8，指针，8 字节
  • 结构体定义 → 只是“图纸”，不分配内存
  • 栈上指针 → p、t 各 8 字节，初值垃圾
  • malloc → 堆上分配，返回 void *，不清零，失败返回 NULL
  • 强制类型转换 → 只改类型，不改地址
  • 栈 vs 堆 → 栈自动回收，堆必须手动 free
最终：p = 0x55A01B00，t = 0x55A01B10；两个结点成员均为垃圾值；程序无任何 printf 输出。
⚠ 原程序缺陷：① 缺 #include <stdlib.h> ② 不检查 NULL ③ 不 free ④ 成员未初始化
