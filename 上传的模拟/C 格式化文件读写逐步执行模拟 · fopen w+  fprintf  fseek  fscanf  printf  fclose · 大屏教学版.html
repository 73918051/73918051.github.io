平台模型与关键考点
平台：64 位，小端序；char=1、int=4、long=4、float=4、指针=8。
FILE 类型：系统库内部结构体；fpp 是 8 字节句柄地址，示意值 0x5A2C。
★ 全局 FILE *fpp：位于静态存储区，程序启动时自动初始化为 NULL；生命周期贯穿全程序，任何函数都能访问，不需要传参。
★ "w+" 模式：w = 写（不存在则新建，已存在则清空为 0 字节）；+ = 可读可写（没有它后面 fscanf 全失败）。
⚠ "w" 是危险模式：会毫不留情覆盖已有内容，没有任何提示。
★ 相对路径 "study"：文件建在程序当前工作目录下（不是源码目录）。
原程序缺陷：第 10 行错误分支缺 exit(1)——文件打开失败时程序仍会继续跑，隐患；%s 未限宽（应写 %80s）；fclose / fprintf / fscanf / printf 返回值未检查。
★ fprintf 的 %f 默认 6 位小数：3.14159 → 3.141590（8 字符）。
★ fseek 是写读切换的关键：写完位置停在 24，不 fseek 会立刻读到 EOF。
★ fseek vs rewind：定位效果一样；rewind 额外清除 EOF 和错误标志、无返回值；fseek 有返回值可检查。
★ fscanf 必须传地址：&l、&fp、&c；数组 s 不用 &。
★ 四个格式符差异：%s 跳前导空白读到下一空白；%ld 跳空白读整数；%f 跳空白读浮点，遇到非数字退回；%c 不跳前导空白，原样读下一个字符。
★ %f 读到 'x' 时退回：位置停在 23，%c 正好读到 x。
★ float 精度陷阱：内存里是 3.141590118...。
★ printf 里 %f 的默认提升：float 被提升为 double。
★ fclose 必须配对：一个 fopen 一个 fclose。
★ return 0：C 语言惯例，0 = 成功，非 0 = 失败。
复杂度：时间 O(1)，空间 O(1)（数据量固定）。
