🖥 平台模型 & 教学要点
◆ 64 位模型 · 小端序：char=1，int=4，指针 =8；struct node 对齐 8，大小 24 字节
◆ 原链表 3 结点：0x1000(Tom/1/85) 0x1020(Jerry/2/92) 0x1040(Spike/1/78)
◆ 新结点：0x1060(Lucy/2/88)，调用 insert(h, 3)
◆ 短路求值：while(t != NULL && j < i-1)，左边 t != NULL 先求；为假时右边被跳过，防止空指针解引用。
◆ 循环退出两种原因：① t == NULL（位置超出范围）；② j == i-1（定位到前驱）。本例是②。
◆ 计数器 j 从 1 开始：表示 t 当前在第几个结点；退出时 j = i-1 = 2。
◆ 中间插入两步：先 p->next = t->next; 后 t->next = p;；顺序不能反，否则会丢失原后继。
◆ ⚠ i == 1 分支隐患：h = p; 只改函数内部的形参副本，无法影响调用者 main 的头指针；正确做法是传 NODE **h 或通过返回值更新。
◆ ⚠ malloc 未检查 NULL：内存不足时返回 NULL，后续 scanf 会崩溃。严谨写法：if (p == NULL) return 0;
◆ ⚠ i < 1 提前返回内存泄漏：此时 malloc 已分配、scanf 已读入，未 free(p) 就返回；正规写法应先 free(p)。
◆ 头文件不完整：缺 #include <stdio.h>、#include <stdlib.h>、typedef struct node … NODE;
◆ printf("Please input name,class,data:") 末尾没有 \n，后续输入会紧接着同一行显示。
